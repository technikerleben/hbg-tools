Die Anlage soll:
    Was ist ein Eingang?

    Ein Eingang gibt der Steuerung eine Information. Beispiele: Ein Taster wird gedrückt. Ein Sensor erkennt eine Kiste.

    Was ist ein Ausgang?

    Ein Ausgang wird von der Steuerung geschaltet. Beispiele: Ein Motor läuft. Eine Lampe leuchtet.

    Was macht eine SPS?

    Eine SPS liest Eingänge, prüft Regeln und schaltet Ausgänge. Das passiert immer wieder sehr schnell.
